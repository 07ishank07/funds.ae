Connect to your website's repository

Changes you make here are saved to GitHub, then the site updates itself within about two minutes.

Getting an access token

  1. On github.com, open your profile picture menu, then Settings, then Developer settings.
  2. Choose Personal access tokens, then Fine-grained tokens, then Generate new token.
  3. Under Repository access, pick Only select repositories and choose this website's repository.
  4. Under Permissions, set Contents to Read and write. Leave everything else as No access.
  5. Set an expiry date, generate the token, and paste it here.

The token is only sent to GitHub. It is never stored in the repository, and it is forgotten when you close this tab.
